## 🚀 Featured Projects

### 🤟 Pakistan Sign Language → English Translation
Real-time sign language recognition and translation system.
- CNN-BiLSTM + Attention model trained on **788 sign classes** (~99% accuracy on internal test data)
- Full pipeline: preprocessing, dataset construction, real-time webcam inference, custom video recording
- Studied domain-gap issues for real-world webcam generalization
- **Stack:** Python · PyTorch · MediaPipe · OpenCV
- 🔗 [Repository](LIEN_REPO_PSL)

### 🎓 EduEnroll – Course Enrollment Platform
Student course enrollment platform built on a **microservices architecture**.
- Spring Boot services with WebFlux, Eureka service discovery and API Gateway
- Frontend service: Thymeleaf (SSR) for authentication, React (CSR) for the dashboard
- **Stack:** Spring Boot · WebFlux · Eureka · React · Thymeleaf
- 🔗 [Repository](LIEN_REPO_EDUENROLL)

### 📚 BookWorm – Library Management System
Desktop library management application.
- MVC architecture with **10 Gang of Four design patterns** implemented
- Persistence with Hibernate + MySQL; documented with class diagrams
- **Stack:** JavaFX · Hibernate · MySQL
- 🔗 [Repository](LIEN_REPO_BOOKWORM)

### 🏥 Medical NLP – BERT Fine-Tuning
Fine-tuning BERT on three tasks (SST-2, MedMCQA, PubMedQA) with a Gradio interface for prediction.
- **Stack:** Python · Transformers · Gradio · Google Colab
- 🔗 [Repository](LIEN_REPO_MEDICAL_NLP)

### 🗺️ Module M2 – Stack Detection, Indexation & Initial Cartography
